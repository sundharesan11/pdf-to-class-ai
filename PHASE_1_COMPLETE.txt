================================================================================
                       AGENTS IMPLEMENTED
================================================================================

1. PDF PARSER AGENT
   - Converts PDFs to structured courses
   - Creates chapters and sections
   - Outputs: ClassStructure (Pydantic model)
   - Tools: extract_text, save_class_to_db, generate_embeddings

2. TUTOR AGENT
   - Teaches via Socratic method
   - Uses RAG (Qdrant semantic search)
   - Provides examples and questions
   - Outputs: TutorResponse (Pydantic model)
   - Tools: get_section, search_vector_db, save_messages

3. QUIZ AGENT
   - Evaluates student answers
   - Provides constructive feedback
   - Adapts difficulty
   - Tracks progress
   - Outputs: QuizResponse (Pydantic model)
   - Tools: search_content, save_attempt, save_progress

4. ORCHESTRATOR AGENT
   - Manages learning flow
   - Decides: teach, quiz, review, next_section, celebrate
   - Monitors student performance
   - Outputs: OrchestrationDecision (Pydantic model)
   - Tools: get_course_structure, get_progress, manage_sessions

================================================================================
                       API ENDPOINTS
================================================================================

PDF PROCESSING:
  POST   /pdf/upload                      Upload and parse PDF
  GET    /pdf/{class_id}/structure        Get course structure

TUTORING:
  POST   /chat/message                    Chat with tutor
  GET    /chat/{session_id}/history       Get conversation history

QUIZZING:
  POST   /quiz/submit                     Submit answer
  GET    /quiz/{session_id}/questions     Get quiz questions

LEARNING SESSIONS:
  POST   /learning/session/start          Start learning
  GET    /learning/session/{session_id}   Get session info
  POST   /learning/session/{session_id}/next  Get next action
  GET    /learning/class/{class_id}/progress  Get progress
